# edge-collect-gateway-demo
边缘Modbus采集网关

## 项目背景
工业边缘侧Modbus TCP数据采集网关，实现PLC寄存器周期性采集，生产者消费者模型异步批量写入MySQL；支持Redis熔断黑名单、采集限流、采集防重复锁，设备在线状态检测、告警防抖、离线数据本地JSON缓存，对外提供FastAPI运维与数据查询接口。

## 技术选型
Python3.9+，FastAPI，pymodbus，pymysql，redis，threading，Queue，pyyaml

## 分层架构
1. 采集层：为每一个Modbus从站启动独立采集线程，循环读取保持寄存器，内置Modbus重连；采集前置校验Redis黑名单、滑动窗口限流、采集防重复锁，防止多实例重复采集。采集结果投递到线程安全队列。
2. 队列缓冲层：线程安全Queue作为生产者消费者中间缓冲，设置队列最大长度，队列满直接丢弃数据，防止内存溢出，削峰填谷。
3. 数据消费持久层：多消费线程从队列读取采集数据，批量组装SQL写入MySQL；内置连接有效性检测；数据库不可用时，写入本地JSON离线缓存。数据库恢复后自动回放缓存数据入库。
4. 控制层：Redis实现设备熔断黑名单、ZSet滑动窗口采集限流、采集防重复锁；Redis不可用时自动降级，切换内存本地黑名单兜底，不阻断采集主流程。
5. API接口层：FastAPI提供健康检查接口、采集统计查询、告警黑名单运维、配置保存接口，附带慢请求中间件监控请求耗时。
6. 日志与本地存储层：滚动文件日志；本地文本持久化采集记录、告警记录、设备统计数据；JSON文件存储离线缓存数据。
7. 辅助后台线程：内存监控线程、设备健康巡检线程、统计计算线程，独立运行，不阻塞主采集业务。

## 启动方式
1. 复制 app.yaml.example 为 app.yaml，修改里面Modbus、MySQL、Redis连接配置
2. 安装项目依赖包：
    pip install -r requirements.txt
3. 执行MySQL建表SQL，提前创建业务数据表 modbus_day2_data
4. 启动主程序：`python v4.py`

## 注意事项
1. app.yaml包含数据库、Redis账号密码等敏感信息，**禁止提交至Git仓库**，仅提交模板文件 app.yaml.example。
2. Redis为可选组件，Redis连接失败程序自动降级，基础采集入库功能不受影响。
3. 可根据PLC设备数量、采集频率，调整队列上限、采集间隔、数据库批量写入条数。
4. 程序支持优雅停机，接收SIGINT/SIGTERM信号，等待线程安全退出。

## 项目说明
本项目为迭代Demo，已完成核心采集、缓存、线上故障修复；全局锁拆分、状态封装属于后续规划优化方案，详见 bug_notes.md。
